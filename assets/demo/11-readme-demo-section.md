1. Install the CLI.
2. `hypnotist build` writes a session from your brief and checkout.
3. Resume that session in Claude Code or Codex and keep working.

## Usage

Build a session from a brief, then resume it:

```sh
hypnotist build --brief brief.json
claude --resume <session-id>
```

Or go straight from a request (use `--dry-run` to print the resume command without launching):

```sh
hypnotist go "what you want to do"
hypnotist go --dry-run "what you want to do"
```

### Common options

| Option | What it does |
|--------|--------------|
| `--target {claude,codex}` | Which CLI session to create (default: `claude`) |
| `--writer {hermes,claude,codex}` | Who writes the note (default: `claude`, i.e. Haiku) |
| `--from FILE` | Add an instruction file as a source (repeatable) |
| `--from-session ID` | Pull your own messages out of an existing Claude/Codex session |
| `--language LANG` | Note language (default: inferred from the request) |
| `--cwd DIR` | Working directory the new session is bound to |
| `--mechanical` | Keyword-based context with no LLM call |

Run `hypnotist build --help` for the full list.

> The session history is generated by Hypnotist from your brief. Review it before relying on it.
